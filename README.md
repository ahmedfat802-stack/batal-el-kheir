# بطل الخير

لعبة موبايل للأطفال (من 4 لـ 7 سنين) عن القيم والسلوكيات: الطفل هو البطل، و10 مواقف بالعامية المصرية مع أصوات، ولعب بسيط بصباع واحد.

- أول ما اللعبة تفتح بتسأل: ولد ولا بنت، واسم البطل. الكلام كله بيتغير على حسب الاختيار.
- إعدادات الأهل: اضغط مطوّل على ⚙︎ في الشاشة الرئيسية.

## تجهيز اللعبة لطفل معيّن
عدّل `config.js`: الاسم، ولد/بنت، الصورة الكرتونية، ملفات صوت الاسم، وخلي `askHero: false`.

## الأصوات
الأصوات معمولة بـ [elevenlabs.io](https://elevenlabs.io). النسخة دي للتجربة بس.
